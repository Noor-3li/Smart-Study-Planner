# 📚 Student Study Planner

A simple and smart **Student Study Planner** that helps students prepare for their exams by creating a personalized study plan.

The student enters their **subjects, exam dates, and available study hours**, and the planner automatically calculates how much time should be given to each subject. 🎓

## ✨ Features

-  Enter your subjects
-  Enter exam dates
-  Enter available study hours
-  Automatically create a study plan
-  Distribute study time between subjects
-  Give more study time to subjects with closer exams
-  Show how many hours to study each subject
-  Create a personalized exam preparation schedule

## 🛠️ Technologies Used

-  HTML
-  CSS
-  JavaScript

## 🚀 How to Run

1.  Download or clone the repository.
2.  Open the project folder.
3.  Open `index.html` in your browser.
